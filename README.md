# Teslo API

1. Clonar proyecto

2. Instalar los paquetes del proyecto
```
yarn install
```
3. Clonar el archivo .env.example y renombrarlo .env

4. Levantar la base de datos

```
docker-compose up -d
```

4. Ejecutar SEED
```
http://localhost:3000/api/seed
```


5. Levantar 

```
yarn start:dev
```
